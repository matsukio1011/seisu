# 樹形図ビジュアライザー (Tree Diagram Lab)

小学校高学年〜高校数学における「場合の数・順列」を、樹形図（ツリーダイアグラム）と計算式スロットで視覚的・直感的に学べるWebアプリケーションです。

---

## 📋 収録問題

### 🟦 【0を含まない】 1〜最大のカード
- **2けたの整数**
- **3けたの整数**
- **3けたの偶数**
- **4けたで両端が奇数**
- **4けたで両端が偶数**

### 🟧 【0を含む】 0〜最大のカード (最高位≠0)
- **3けたの整数**
- **3けたの偶数**
- **3けたで両端が奇数**
- **4けたの整数**
- **4けたで両端が奇数**
- **4けたで両端が偶数**
- **5けたで両端が奇数**
- **6枚すべて並べる整数**
- **6枚すべて並べて両端が偶数**

### 🎯 【数字・範囲の指定】
- **3けたの範囲指定 (何以上 / 何以下)**：
  - 数値入力欄で **1の位まで自由に入力可能**（例: `400`, `420`, `425`, `312` など）！
  - 「以上 (≧) / 以下 (≦)」をワンクリックで切り替えられ、百の位ごとの場合分け計算式（小計・合計）を自動表示。
- **4けたの範囲指定 (何以上 / 何以下)**：
  - 数値入力欄で **1の位まで自由に入力可能**（例: `3000`, `3150`, `3420` など）！
  - 千の位ごとの場合分け計算式（小計・合計）と樹形図が完全連動。

### 📖 【辞書式配列】英単語の順列
アルファベット順に配列したとき、目的の英単語が「第何番目か」を求める定番問題です。
- **4文字の問題 (総数 24通り)**：
  - **[1] MATH は何番目？**（第 **14番目**）
  - **[2] STAR は何番目？**（第 **17番目**）
  - **[3] BLUE は何番目？**（第 **4番目**）
- **5文字の問題 (総数 120通り)**：
  - **[4] SMILE は何番目？**（第 **118番目**）
  - **[5] CLOUD は何番目？**（第 **10番目**）
  - **[6] TRAIN は何番目？**（第 **115番目**）
- **6・7文字の問題 (720〜5040通り)**：
  - **DRAGON は何番目？**（総数 720通り / 第 **218番目**）
  - **ORANGE は何番目？**（総数 720通り / 第 **582番目**）
  - **PENCIL は何番目？**（総数 720通り / 第 **643番目**）
  - **PLANET は何番目？**（総数 720通り / 第 **531番目**）
  - **ENGLISH は何番目？**（総数 5040通り / 第 **496番目**）
※ 樹形図上で目的の単語がゴールドに光り、左パネルには参考書のような「ステップ別の手計算（小計と合計）」が完全自動表示されます！

### 🎓 【教科書の定番問題】
高校数学Aや入試で頻出する、樹形図の超定番問題5選を完全再現！
- **[1] 先に2勝で優勝（A vs Bの試合）**：
  - どちらかが先に2勝した時点で試合終了となるため、AAやBBは第2試合で終了（途中で止まる樹形図）。勝敗の決まり方は全部で **6通り**。
- **[2] プレゼント交換（完全順列・3〜6人変更可能）**：
  - 全員が自分の持ってきた物以外のプレゼントをもらう配り方（モンモール数・攪乱順列）。人数を **3人（2通り）**、**4人（9通り）**、**5人（44通り）**、**6人（265通り）** から自由に切り替え可能！A君がもらう物ごとの対称性や計算式がリアルタイムで完全連動します。
- **[3] 隣り合わない3桁の整数（1, 2, 3）**：
  - 1, 2, 3 を使って同じ数字が隣り合わない整数を作る問題。百の位（3通り）× 十の位（2通り）× 一の位（2通り）＝ **12個**。
- **[4] コインと数直線の移動（座標が1）**：
  - 原点0から表で+1、裏で-1。3回投げて最終座標が1になる出方（表2回・裏1回）の **3通り**（全体8通り中）をエメラルドグリーンでハイライト。
- **[5] 赤玉・白玉の取り出し（色が異なる）**：
  - 赤玉2個を「赤1」「赤2」と区別して数える確率・場合の数の鉄則を視覚化。色が異なる取り出し方は **4通り**（全体6通り中）。

### 📦 【集合】部分集合の個数
手書きメモにある「`{a, b, c} の部分集合`」を忠実に樹形図化した新ジャンルです。
- **{a, b, c} の部分集合**（要素数は `2個`〜`5個` まで自由に変更可能）
  - 各要素（$a, b, c$）に対して「部分集合に入る（○）」「入らない（×）」の2分岐を行うことで、全体で $2 \times 2 \times 2 = 2^3 = 8$ 個の部分集合が作られます。
  - 樹形図の先端（葉）には、手書きメモに書かれている部分集合が上から順にそのまま表示されます：
    - `○○○` ➡ `{a, b, c}`
    - `○○×` ➡ `{a, b}`
    - `○×○` ➡ `{a, c}`
    - `○××` ➡ `{a}`
    - `×○○` ➡ `{b, c}`
    - `×○×` ➡ `{b}`
    - `××○` ➡ `{c}`
    - `×××` ➡ `∅ (空集合)`
  - 要素 $a$ が「○」のグループ（4個）と「×」のグループ（4個）の手書きメモの樹形図構成も、上部の「👑 要素 a」ボタン（`○` / `×`）でそれぞれ独立して観察できます！

## 🌟 主な機能と特徴

1. **🃏 カードの最大値を「4」「5」「6」から自由に変更可能（新機能！）**
   - カードの問題を選んだ際、左パネルの問題概要欄に **`[4] [5] [6]` の最大カード切り替えボタン**が表示されます。
   - 最大値を切り替えると：
     - 使えるカード一覧（例：`1〜4` / `1〜5` / `1〜6` や `0〜4` / `0〜5` / `0〜6`）が更新。
     - 樹形図、スロットの掛け算式、場合分けの計算、全通り数が**リアルタイムで自動再計算**されます。
     - 上部の「👑 最高位」「🎯 一の位」の候補ボタンも連動して自動更新されます。

2. **👑 最高位 ＆ 🎯 一の位を選んでクローズアップ描画**
   - 画面上部にある「最高位（百/千の位）」および「一の位」カードボタン（`全`, `0`, `1`, `2`, `3`, `4`, `5`）で、**特定の数字に絞り込んだ樹形図を瞬時に拡大描画**できます。
   - **一の位の指定（偶数や倍数の考察）**：例えば一の位を「2」にすると、末尾が2で終わる枝のみを抽出。
   - **最高位と一の位の同時指定**：例えば千の位を「2」、一の位を「0」にすると、手書きメモ⑧にある `2 _ _ 0` の12通りの樹形図だけをピンポイントで確認できます！
   - 「百の位が【1】のときは12通り、他の数も同じ12通りだから、12通り × 5 ＝ 60通り！」といった**掛け算の対称性・教育的ポイントが左パネルに動的に表示**されます。

2. **手書きメモの計算式＆場合分けの完全再現**
   - ⑥の「32通り + 20通り = 52通り」や、⑧の「12通り + 12通り + 24通り = 48通り」のような**場合分けの小計と合計**を左パネルに美しく表示。
   - 条件に一致する枝はエメラルドグリーンで光り、「条件を満たすもののみ表示」で該当する枝だけをスマートに抽出できます。

2. **PC画面・スクロール完全ゼロ設計**
   - 画面全体を `100vh / overflow: hidden` に設定し、ブラウザのスクロールバーが一切発生しません。
   - 枝が多い場合（100通りや72通りなど）でも、画面サイズを自動検知して**全体が画面内にピッタリ収まる自動スケーリング（全体フィット）**を行います。

3. **ダークモード標準搭載**
   - 目が疲れにくいモダンなダークテーマを標準適用。ヘッダーのボタンからライトモードへの切り替えも可能です。

4. **全画面表示ボタン（Fullscreen）**
   - ヘッダー右上の**「全画面」ボタン**（または `F11`）を押すと、ブラウザ枠を隠してアプリ画面いっぱいに樹形図を表示できます。

5. **インタラクティブな樹形図の学習・操作機能**
   - **ステップ描画（アニメーション再生）**：枝が1本ずつ伸びていく過程を順を追って再生（速度調整付き）。
   - **経路ハイライト＆スロット連動**：ノードや数字にカーソルを合わせると、根から葉までのルートが光り、左側のスロット（`_ _ _`）に数字がリアルタイムで反映されます。
   - **先頭の枝フィルタ**：「先頭が 1 の枝だけ見る」などに絞り込むことで、樹形図の規則性をじっくり観察できます。
   - **マウス操作**：右画面のドラッグで移動（パン）、ホイールで拡大縮小（ズーム）が自由自在。
