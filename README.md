# 算数・数学トレーニングシリーズ (seisu)

Webブラウザ上で手軽に学べる算数・数学トレーニングアプリ集です。  
PC画面でスクロール不要（1画面完結）でテンポよく反復練習ができる設計になっています。  
全アプリで**ダークモード**および**全画面表示（Fキー / ボタン）**に対応しています。

## 収録アプリ

1. **アプリ選択ポータル (`index.html`)**
   - 各トレーニングアプリへのハブ画面。キーボードの `1`, `2`, `3` または矢印キーで素早く起動できます。

2. **分数 約分マスター (`bunsu.html`)**
   - 1〜50の真分数の約分判定・計算トレーニング。
   - 4択形式、初級モード、3の倍数特化モードなどを搭載。

3. **倍数マスター (`baisuu.html`)**
   - 2, 3, 4, 5, 6, 9 の倍数を瞬時に見分ける判定トレーニング。
   - 初級（1つの数で割れるかの2択・指定数またはランダム）および総合（4択）の2モード。
   - 2桁〜5桁の桁数選択に対応。

4. **数分類マスター (`seisu.html`)**
   - 自然数、負の整数、素数、絶対値などの数学用語と条件に合致する数を8枚のカードから選択。
   - 連続正解で突入する演出モードを搭載。

## 特徴

- **1画面完結UI**: PC画面スクロール不要のレスポンシブ配置。
- **全画面表示**: ヘッダーの切り替えボタンまたは `F` キーで全画面表示のON/OFFが可能。
- **ダークモード**: ヘッダーのテーマボタンでライト／ダークをワンクリック切り替え（設定は自動保存）。
- **キーボード完全対応**: テンキーや数字キー、スペース／Enterキーで素早くテンポよく解答可能。
- **スタンドアロン動作**: サーバー構築や事前ビルド不要。HTMLファイルを開くだけですぐに動作します。
