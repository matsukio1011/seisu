# 算数・数学トレーニングシリーズ (seisu)

Webブラウザ上で手軽に学べる算数・数学トレーニングアプリ集です。  
PC画面でスクロール不要（1画面完結）でテンポよく反復練習ができる設計になっています。  
全アプリで**ダークモード**および**全画面表示（Fキー / ボタン）**に対応しています。

## 収録アプリ

1. **アプリ選択ポータル (`index.html`)**
   - 各トレーニングアプリへのハブ画面。キーボードの `1`, `2`, `3`, `4`, `5`, `6`, `7`, `8`, `9`, `0`, `-`（または `M`）あるいは矢印キーで素早く起動できます。

2. **分数 約分マスター (`bunsu.html`)**
   - 1〜50の真分数の約分判定・計算トレーニング。
   - 4択形式、初級モード、3の倍数特化モードなどを搭載。

3. **倍数マスター (`baisuu.html`)**
   - 2, 3, 4, 5, 6, 9 の倍数を瞬時に見分ける判定トレーニング。
   - 初級（1つの数で割れるかの2択・指定数またはランダム）および総合（4択）の2モード。
   - 2桁〜5桁の桁数選択に対応。

4. **数分類マスター (`seisu.html`)**
   - 自然数、負の整数、素数、絶対値などの数学用語と条件に合致する数を8枚のカードから選択。
   - 連続正解で突入する演出モードを搭載。

5. **式の展開・因数分解マスター (`tenkai/index.html` または `tenkai.html`)**
   - **モード1: 展開の工夫 (4択クイズ)**
     - 多項式の積を展開しやすくするための式変形（和と差の積 $(A+B)(A-B)$ の作成）トレーニング。連続10問合格画面、お名前登録＆所要時間ランキング、解答履歴機能を搭載。
   - **モード2: 因数分解の変形 (8枚◯✕チェック)**
     - $A^2 - B^2 = (A+B)(A-B)$ の途中変形（中カッコ、平方根、マイナス符号の分配）について、8枚のカードに◯か✕をつけてから判定する特訓アプリ。式がカードからはみ出ない自動スケーリング機能・詳細解説付き。
   - ヘッダー中央のモード切替タブまたは **`M` キー**でいつでもワンクリックで切り替え可能です。

6. **帯分数マスター (`taibunsu.html`)**
   - 仮分数を正しい帯分数に直す計算練習トレーニング。
   - 純粋な仮分数だけでなく、整数部分を含む仮帯分数（例: $2\text{と}\frac{7}{5}$）への対応や、分子・分母の桁数カスタマイズに対応。
   - 既約分数判定・詳細なステップ解説・キーボード解答（`1`〜`4`）を搭載。

7. **間違いやすい方程式 6択特訓 (`houteishiki.html`)**
   - 係数で割るのか掛けるのか、符号はどうなるかなど、中高生がつまずきやすい1次方程式の変形を6択形式で徹底特訓。
   - 「両辺正」「両辺負」「正と負」「ランダム」の符号モード切替に対応。
   - 間違いやすい典型的なトラップ（逆数・乗算誤り・符号反転）を選択肢に自動生成。KaTeXによる数式描画、キーボード解答（`1`〜`6`、`Enter`/`Space`で次へ）対応。

8. **速さマスター (`hayasa.html`)**
   - 速さ・道のり・時間の関係（「はじき」「みはじ」）を瞬時に見抜く暗算特訓トレーニング。
   - **問題形式の選択**: 「基本問題（定型表現）」「標準問題（文章題・実践シチュエーション）」
   - **求める量の選択**: 「速さ」「道のり」「時間」
   - **答えの形式の選択**: 「整数」「小数」「分数」
   - **単位表記の選択**: 速さの表記スタイルを「時速km（時速40km、分速80mなど）」と「km/時（40km/時、80m/分など）」から選択可能。
   - **公式ヒントの表示切替**: 問題画面およびフッターの公式ヒントを「表示 / 非表示」で切り替え可能（自力想起の特訓に対応）。
   - **テンポの良い進行**: 正解時は自動的に次の問題へ進み（ディレイ付き）、不正解時は詳細な解説バナーでじっくり確認可能。
   - 計180問の高品質問題データベース、4択形式、KaTeXによる数式描画、キーボード解答（`1`〜`4`、`Enter`/`Space`で次へ）、10問連続合格演出（ほのねこ登場）を搭載。

9. **ドパ倍数 (`dopabaisuu.html`)**
   - ドパドリル風のポップで爽快なビジュアルとWeb Audio効果音・BGMを搭載した倍数判定トレーニング。
   - **問題形式**: 初級（2択）および総合（4択）。
   - **桁数選択**: 2桁、3桁、4桁、5桁、2〜5桁ランダム。
   - **モード**: じっくり解く「練習モード」と、制限時間内にハイスコアを目指す「60秒タイムアタックモード」。
   - **サポート機能**: 2, 3, 4, 5, 6, 9の判定法を学べる「見分け方のコツ・早見表」モーダル、解答履歴・ログ表示、演出・音声切り替え対応。

10. **等式 ◯☓ジャッジ (`toshikimarubatu.html`)**
    - 展開・因数分解・対称式の等式（全275問）から6枚のカードを◯か☓で判定するトレーニング。
    - **出題分野・公式タイプ選択**: 「展開だけ（すべて / $(x+a)(x+b)$ / $(a+b)^2$ / $(a+b)(a-b)$）」「因数分解だけ（すべて / 共通因数 / $x^2+(a+b)x+ab$ / $a^2+2ab+b^2$ / $a^2-b^2$）」「対称式だけ」「ミックス」から選択可能。
    - **係数の種類選択**: 「整数だけ」「小数・分数を混ぜる」を切り替え可能。
    - **連続正解目標の選択**: 3回・5回・10回・15回・20回連続パーフェクトから合格目標を設定可能。
    - **ドパモード搭載**: BGM・効果音・紙吹雪・レベルアップ（LV.1〜LV.9）演出・派手なカスタムカーソル＆軌跡エフェクトを搭載（ON/OFF切替可）。

11. **割合・暗算アニマル道場 (`wariai.html`)**
    - 「$A$の$B$は$C$」「$C$は$A$の$B$」の割合の基本構造を、3段階の動物レベルで直感的にマスターする暗算特訓アプリ。
    - **難易度（動物）**:
      - 🐰 **ウサギ級**: 九九だけで一瞬で解ける癒やし系レベル（キリの良い数・100〜1000の暗算）
      - 🐕 **ボーダーコリー級**: 1ステップの掛け算・割り算の身のこなしを楽しむ実戦レベル（320の20％など）
      - 🐯 **野生のトラ級**: 「倍と半分」や「分数化」を武器に挑む上級レベル（450の36％など）
    - **カスタマイズ機能**:
      - 文型切替（「$A$の$B$は$C$」/「$C$は$A$の$B$」/「🎲混ぜる」）
      - 空欄（□）の場所（元数$A$ / 割合$B$ / 結果$C$ / ランダム）
      - 割合の表記形式（％ / 歩合 / 小数 / 分数 / すべてランダム）
      - 連続正解目標（5問 / 10問 / 20問 / なし）
    - **お祝い合格演出**: 目標達成時に動物たち（ウサギ・コリー・トラ）が跳ねてお祝いしてくれる豪華なSVGイラスト・ファンファーレ効果音・紙吹雪（Confetti）演出を搭載。

12. **文字式の表し方 4択マスター (`mojishiki.html` または `mojishiki/index.html`)**
    - 中学1年数学「文字と式」の文章題・数量の表し方を4択形式で徹底マスターするトレーニング。
    - **全15パターン完全収録（計450問）**:
      1. 積の表し方（記号省略・係数・アルファベット順・累乗）
      2. 商の表し方（分数表記・逆数）
      3. 積と商の混じった式
      4. 代金・おつり
      5. 個数・余り・不足
      6. 平面図形（長方形・三角形・円・平行四辺形・台形・ひし形等の周の長さと面積）
      7. 空間図形（直方体・立方体・円柱・角柱・円錐・角錐・球の表面積と体積）
      8. 平均
      9. 2桁・3桁の整数
      10. 速さ（道のり・時間・速さ）
      11. 速さの単位変換
      12. 割合（％・歩合・割増・割引）
      13. 食塩水（食塩の量・濃度）
      14. 等式による関係の表し方
      15. 不等式による関係の表し方
    - **リアルな誤答選択肢**: 生徒がつまずきやすい典型的な誤答（符号ミス、積商の混同、単位のズレなど）を4択に配置。
    - **速さの単位表記切替**: 「分速 $m$（分速80mなど）」と「$m$/分（80m/分など）」の表記切替に対応。問題文と全選択肢がリアルタイムに連動。
    - **快適な学習テンポ**: 正解時は自動で次の問題へ進み、不正解時は正解と詳細解説をじっくり確認可能。
    - **Web Audio効果音＆合格演出**: 正解ピンポン音・不正解ブブー音・目標達成時のファンファーレ＆紙吹雪を搭載。目標連続正解数（5/10/20問/なし）を設定可能。
    - **いつでも見られる解答履歴**: モーダルから直近の解答履歴・選択・正誤を即座に確認可能。
    - **キーボード対応**: `1`〜`4` キーで瞬時に解答、`Enter`/`Space`で次へ。

13. **ルートで約分マスター (`rootyakubun.html`)**
    - 分母分子をルートで割って瞬時に有理化する感覚を養う計算トレーニング（全150問収録）。
    - **3段階の出題コース**:
      1. 📕 **上級発展型**: $\frac{16 - \sqrt{40}}{\sqrt{8}}$ （分母が $\sqrt{8}, \sqrt{12}, \sqrt{18}$ などの平方因数を含む発展型、全50問）
      2. 📙 **多項基本型**: $\frac{6 - \sqrt{10}}{\sqrt{2}}$ （分子の整数とルートをそれぞれ分母のルートで約分、全50問）
      3. 📘 **単項基本型**: $\frac{6}{\sqrt{2}}$ （分子をルートの中身で割って $\sqrt{}$ をつける基本型、全50問）
      4. ⚡ **オールミックス**: 全150問からランダム出題。
    - **リアルな誤答選択肢**: 左項のルート忘れ、符号のミス、右項の約分忘れ、分母の $a\sqrt{b}$ 変形忘れなどを4択に配置。
    - **連続正解目標＆合格演出**: 5問・10問・15問・20問・30問・50問連勝の目標を設定可能。目標達成時に華やかなファンファーレ効果音と金色の紙吹雪演出で合格証を表示。
    - **快適仕様**: 1問ごとの自動進行、PC完全スクロールレス、全画面表示、キーボード解答（`1`〜`4`・テンキー）対応。

## 特徴

- **1画面完結UI**: PC画面スクロール不要のレスポンシブ配置。
- **全画面表示**: ヘッダーの切り替えボタンまたは `F` キーで全画面表示のON/OFFが可能。
- **ダークモード**: ヘッダーのテーマボタンでライト／ダークをワンクリック切り替え（設定は自動保存）。
- **キーボード完全対応**: テンキーや数字キー、スペース／Enterキーで素早くテンポよく解答可能。
- **スタンドアロン動作**: サーバー構築や事前ビルド不要。HTMLファイルを開くだけですぐに動作します。
